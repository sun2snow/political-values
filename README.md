96道中文题，10个候选维度，原创探索性问卷。**未经真人样本校准，不宣称测量准确性已获验证。**

静态网页，直接使用 GitHub Pages 的 `main` 分支根目录发布。自定义域名：`zz.sun2snow.dpdns.org`，DNS CNAME 指向 `sun2snow.github.io`。

## 功能

- 分页作答、跳过和修改、题目导航、独立显示有效计分题数。
- 本地计分；保存进度需主动勾选，不使用账号、后端或分析追踪。
- 十维画像、情境条件对比、谨慎的思想传统参考。
- 原始答案JSON导入导出、Markdown报告下载、浏览器打印/PDF。
- 自适应手机和桌面布局、键盘操作及原生表单控件。

## 本地运行与检查

```sh
python3 -m http.server 8765 --directory . --bind 127.0.0.1
```

访问 `http://127.0.0.1:8765`，不要直接用file协议打开。

```sh
node --test tests/core.test.mjs
python3 -m unittest discover -s docs -p 'test_*.py'
```

`data.json`为正式网页题库及标签规则，`core.mjs`为无DOM纯计分逻辑，`app.js`为交互。`docs/`保留原始Python计分及方法文档。修改题意、方向、阈值或规则必须同步来源、升版本并重新验证。测试使用虚构答案；不包含真实用户答案。

## 隐私与测量限制

答案不上传、不写入URL。GitHub Pages仍可能记录IP等访问日志。浏览器保存及下载文件由使用者控制；共用设备建议不保存。HTTP/HTTPS和不同域名的存储独立。删除网站进度不会删除下载文件。

问卷结构、预计25—35分钟用时、信效度与跨地区适用性均待真人验证。图中左右只是端点，分数不是人口百分位、准确率或价值优劣。思想传统提示可以并存，不是身份判定。
