# 分数怎么算，为什么会增加题目？

版本：2.1.0-exploratory。新版改写了题目，并加入补充题。它仍是一份用于自我了解的探索性问卷，尚未证明能准确判定一个人的政治身份。

## 先答96题，必要时再问一点

基础部分有80道立场题、12道情境题和4道作答反馈。80道立场题分成10个方面，每个方面8题。情境题与反馈不计入立场分数。

如果同一方面的基础答案比较分散，系统会在基础部分后增加4道补充题，换一些情境继续了解你的想法。最多10个方面各补4题，基础与补充合计最多136题；如触发澄清，还会增加10道不计分题。补充题可以跳过，回答不同不代表你答错或撒谎。

补充题是“多了解一点”，不是让你把答案改得一致。它们不能保证结果更准确，也不能代替真实样本的测量验证。

## 如何判断答案比较分散

这是供愿意了解计算细节的读者查看的规则，不需要先学会它再作答。

1. 将1—5的答案先变为−2、−1、0、1、2。反向题再乘以−1，让所有题的计分方向一致。
2. 每个方面至少有6道有效基础答案，才判断是否需要补充。无法判断、题意不清和跳过不算有效答案。
3. 计算这些数的**总体方差**：每个数减去平均数，平方后再求平均。如果方差至少为1.5，并且至少两题向左、两题向右，就触发该方面的4道补充题。
4. 每方面的补充题固定为09—12号，两个方向各2题。只根据基础答案决定是否触发，不根据补充答案继续加题，因此不会无限增加。

例如，统一方向后全部是1，方差为0，不加题；一半是−2、一半是2，方差为4，会加题。原始答案全选“非常同意”也可能触发，因为同意方向相反的主张会产生分散的结果，但这不是无效作答判定。

1.5、至少6题、两边各至少2题，都是公开的设计约定，尚未经过真人数据校准。这不是已经完成测量标定的计算机自适应测验。

## 分数怎样计算

每个方面必须有至少6道有效**基础**答案才显示分数，补充题不能代替这个门槛。

统一方向后的答案记为z，平均值记为m。分数＝25×(m＋2)，范围0—100。基础分只用基础题；当前分数把已触发且有效回答的补充题一并纳入，所有题等权。补充题没答或选“无法判断”时，不填成中立，也不改变均值。

结果会同时列出基础分、回答了多少补充题、包含补充题的当前分数，以及不同方向的答案数量。最贴近的意识形态使用当前分数。没有补充答案时，当前分数等于基础分。

若回去修改基础答案，系统会重新判断该方面是否需要补充。已经填写的补充答案保留，便于再次触发时恢复；但不再触发的补充答案不显示在当前题目中，也不计分。导出时会保留它们，以免你丢失作答。

## 如何理解中间分数

全选中立，与在不同问题上选择不同方向，可能得到同样的平均分。因此，结果会另外展示左向、中立、右向的题数，不把二者都叫作“温和中间派”。

≤35与≥65用于提示偏向哪端；这些阈值不是自然界划定的政治阵营界线。左右只是图上的位置，不等于传统政治左右派。分数不是准确率、人口排名或道德水平。

## 旧版答案怎样处理

相对v1，v2使用单独的本地进度。v1进度不自动搬到新版，也不会被新版覆盖。v1答案文件与没有版本的答案对象，请到[旧版问卷](../legacy/v1/)使用。

新版导出的JSON包含format、version、answers和clarifications。支持当前v2.1及v2.0答案文件。核心题和补充题接受整数1—5、U、Q或null；情境题接受A/B/C/U或null；反馈题接受整数1—5或null。未知编号、错误类型、重复编号及不符的版本会被拒绝。

## v2.1澄清与兼容

额外10道澄清题不计分。只有初步最近画像为中间主义时使用，完整阈值见[归纳方法](最贴近意识形态规则.html)。最多96+40+10=146题。

导出格式仍为 `political-values-answers`，版本为 `2.1.0-exploratory`；`answers` 保存基础、补充、情境与反馈答案，独立的 `clarifications` 对象保存 `C_D1`—`C_D10`，取值见[澄清题](澄清题.html)，空值或缺失表示跳过。导入v2.0文件时保留原答案，澄清题留空；v1继续使用旧入口。当前浏览器v2进度原地兼容，澄清答案只在主动勾选保存后保存在设备中。
