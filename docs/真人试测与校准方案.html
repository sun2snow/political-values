计分与补充题思想传统参考试测计划

真人试测与校准方案（v2）

新版追加的验证任务

优先招募具有初中教育经历的成年人进行认知访谈，请他们用自己的话复述题目，并记录不认识的词。不能只根据句子变短就宣称达到某一阅读年级。

单独检查40道补充题是否测量同一方面、方差触发规则是否有用、是否增加疲劳。比较基础分与补充后的分数、重复测量稳定性及参与者对解释的理解。不把补充后方差变小视为正确答案，也不强求不同观点合并。由于不同人回答的题数不同，未经校准前不得据此做人口排名或跨人精细比较。

目标与阶段门槛

目的不是让问卷产生漂亮的二维坐标，而是检验：题意是否被正确理解、候选维度是否成立、分数能否稳定且有意义地反映自述立场。当前未招募参与者，本文是待执行方案。所有样本量为规划目标，应在正式研究前结合模型复杂度和预试结果评估精度；800人不自动保证分析充分。

招募与知情同意

面向18岁及以上、能独立理解中文的自愿参与者。通过多个非单一政治社群渠道招募，尽量覆盖年龄、教育、城乡和生活地区。使用目的抽样和配额提高多样性，不将便利样本称为人口代表样本。国家或地区差异应谨慎记录为可选的宽泛类别，不收集精确位置。

同意页面须说明：研究目的、政治观点敏感性、自愿跳题和退出、实际收集字段、访问者、保存期限、公开范围及联系渠道。不同意者不进入问卷；未满18岁者不进入本轮研究。不要要求公开个人政治立场。

默认仅收集随机研究编号、问卷版本、题目答案、总作答时间和四道反馈。年龄段、教育与宽泛居住地区用于偏差分析，全部可不答；不用姓名、账号、设备指纹或精确IP定位。若使用网络平台，应先核实其日志与第三方追踪设置，不能仅因问卷不问姓名就宣称完全匿名。

重测由参与者自行保留随机配对码；可另行自愿提供联系方式，联系方式与答案分库保存，仅用于一次重测邀请，邀请结束后删除。参与者在去关联汇总前可凭撤回码请求删除；完全去关联后可能无法定位其记录，须事先说明。原始数据默认限制研究人员访问，研究结束后12个月删除；只公开去标识化汇总和方法，个体答案不默认公开。正式开展前根据机构和所在地要求确定伦理审查及数据责任人。

访谈脚本与内容审查表

针对每题询问：①请用自己的话复述；②你想到了哪个国家、机构或具体事件；③哪些条件会让你改变答案；④3、U与Q是否能区分；⑤是否有两部分想选不同答案；⑥是否觉得某选项显得更有道德。不要向参与者讲解“正确意识形态”。

审查字段：题号、预期维度、参与者释义、未预期假设、误解类型、文化适用性、建议改写、改写理由、是否改变测量意图、复核结果。尤其检查D2公共规划与劳动参与、D3公共卫生与安全自由、D5专家与代表、D6文化保护与自主、D7公民普遍主义与同化是否混为一谈。

分析计划

题目与缺失

报告各题1—5分布、U/Q/跳过比例、总用时及反馈分布。题意不清或无法判断合计超过15%、单一选项超过80%、或某群体理解差异明显时，列入优先复核；这些是筛查约定，不是自动删题门槛。高一致、极端或直线答案不得单独导致剔除。

重复研究编号、技术性空记录与撤回记录按预先约定处理；同一编号有多个版本时保留时间较早的完整记录作为主分析，其他记录保留审计标记。没有身份跟踪不能保证识别所有重复参与，必须报告这一局限。低自述注意力可作敏感性分析分层，不在主分析中任意清除。公布招募数、同意数、完成数、各维度可报告人数及分析缺失处理。

个人计分仍用至少6/8题的规则。研究因素分析不得把U/Q转成3，也不得直接把个人均值填回缺失项。先报告缺失模式；低缺失时可使用适合有序数据的可用配对相关并报告各对样本数，与完整案例结果比较。缺失较多或非随机迹象明显时，在验证样本开启前选定适当的有序变量缺失模型并冻结方案；证据不足时暂停结构结论，而不是用插补掩盖问题。

结构、信度与外部关系

  • 探索样本按有序变量处理，使用多分相关、平行分析和允许因素相关的探索分析。检查是否支持10因素，是否有措辞方向因子、跨负荷或两个端点不构成同一轴。
  • 验证样本检验探索阶段冻结的模型，使用适合有序题的确认性因素分析。联合检查负荷、残差、因子相关及拟合；CFI/TLI、RMSEA、SRMR均需报告，不以单一阈值判定量表有效。模型不稳定或不收敛时说明问题，不只展示最好模型。
  • 报告各维度ω及区间，暂用ω≥0.70作筛查参考；不为提高一致性而删光重要议题。高一致性不证明单维性或内容全面。
  • 重测使用绝对一致性的单次测量ICC及区间，暂用ICC≥0.70作筛查参考。分别报告自述观点稳定者与发生变化者；不能把所有变化都归为误差。
  • 外部比较在征得授权并核对译本效度、许可与适用语境后进行。可优先考察已有的经济平等、社会价值、公民自由、社会支配和权威态度量表，事先声明预期相关及区分关系。自我意识形态标签可选填，只作辅助，不作为正确答案。
  • 群体样本足够时，对可比地区、年龄和教育组进行有序多组测量等值性及题目差异功能分析，控制多重比较并关注效应大小。组别过小仅作描述，不贸然宣布“公平”或“无偏”。

修改与发布决策

题目去留综合内容覆盖、理解结果、负荷、跨负荷、偏差和稳定性；保留修改日志。若一个维度分为两个独立因素，就拆分或暂不报告，不能为了维持漂亮的10轴图强行平均。删题后未验证的新量表不沿用旧版阈值和报告承诺。

首轮正式报告公布样本来源、分析脚本、版本和主要失败结果。只有得到可靠常模和误差估计后，才讨论百分位或个人区间；未证明跨地区等值性前，不比较地区平均分的高低。标签规则另需验证其可理解性和误导风险，不因维度信度合格而自动视为标签分类准确。

首版主要成功标准是问卷可理解、计分可复核、局限明确；“准确的意识形态判定”仍须后续数据支持。若用时不符合25—35分钟或结构不成立，如实修订版本，不把未经完成的试测写成通过。

v2.1中间主义误判评估

真人访谈分别招募明确支持折中、跨议题混合、尚未形成观点的参与者，先独立访谈再对照问卷。同时统计混合者被判为中间主义和真实温和者被排除的情况；不以单纯降低中间主义比例作为成功指标。记录澄清题阅读障碍、跳过率和作答耗时，不收集真实姓名等身份信息。未经验证不承诺准确率提升。
