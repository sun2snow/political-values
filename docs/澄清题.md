# 中间位置的10道澄清题

只有初步结果最接近中间主义时，才会出现这组题。每个方面一道，不预选答案，也不改变维度分数。你可以逐题跳过，也可以直接查看结果。

统一提问：回看刚才的回答，在下面这组取舍中，哪种描述更接近你的想法？

| 编号 | 方面 | 前一种 | 后一种 |
|---|---|---|---|
| C_D1 | 经济分配 | 少收税，更多自己承担生活开支 | 多收一些税，提供更多公共保障 |
| C_D2 | 经济管理 | 更多由市场信号配置资源 | 更多由公共机构安排资源 |
| C_D3 | 个人权利 | 为安全允许更多限制 | 更严格保护个人自由 |
| C_D4 | 权力监督 | 集中决策，提高执行速度 | 分散权力，加强监督 |
| C_D5 | 公众参与 | 更多由授权的代表或机构作最终决定 | 更多由公民直接作最终决定 |
| C_D6 | 传统与生活 | 公共规则更优先维护传统规范 | 公共规则更尊重个人生活选择 |
| C_D7 | 文化与身份 | 更多强调共同文化 | 更多支持不同文化共存 |
| C_D8 | 国家与世界 | 更多优先照顾本国 | 更多承担国际合作责任 |
| C_D9 | 对外安全 | 同等条件下更优先考虑军事威慑 | 同等条件下更优先考虑外交协商 |
| C_D10 | 环境与发展 | 更多照顾眼前就业和收入 | 更多保护环境和后代利益 |

## 每题选项

- `first`：我通常更支持前一种做法。
- `second`：我通常更支持后一种做法。
- `compromise`：我通常支持两者之间的折中做法。
- `conditional`：要看具体事情；有些支持前一种，有些支持后一种。
- `unsure`：我还没有想清楚。
- `unrepresented`：这两种说法不能表达我的想法。

选了任一选项，就算完成一道澄清题；跳过不算完成。只有选择 `compromise` 才算明确支持折中，尚未想清楚、选项无法表达想法或跳过都不算。完整归纳规则见[思想传统参考](最贴近意识形态规则.html)。
