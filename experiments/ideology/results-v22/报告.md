- 开始：2026-11-18T00:51:13.885Z；结束：2026-11-18T00:59:29.014Z。问卷版本：`2.2.0-exploratory`。
- 候选：`gpt-5.6-luna`、`gemini-3.5-flash-lite`、`grok-4.7-build-fast`，均通过 CLIProxyAPI 实际响应探测；未调用 Claude。候选是三个模型家族中可用的文本模型样本，不是 API 所有模型的穷举。

- 已按当次规则复核分数和内部归纳；排名与命中保留原实验口径，不等同于网页给出该标签。另用 nearest-tradition-2.3 回放相同答卷的页面展示，没有重新请求模型。

## 范围与限制

- 每种角色最多一份有效正式模拟答卷，结果会受模型版本、提示词与采样变化影响。探针选模、角色写法和现有坐标都带有设计者假设。真实误判率、区分效度和人群分布仍需真人研究。
- 不应调提示词来追求所有标签命中。尤其要区分：模型有无遵守角色描述、问卷是否测到了关键观念，以及归纳规则如何选择最近参考点。
- `protocol.json` 记录预先指定的角色、探针及评分锚点；`pilot.json` 记录各模型探针输出；`calls.jsonl` 记录每次请求的状态、耗时和经校验的回答；`results.json` 包含原始答案包、完整十维分数及归纳细节。没有保存 API 密钥或服务地址。
