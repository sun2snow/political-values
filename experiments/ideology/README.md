# 24 种参考画像的模拟作答实验

这项实验把三个通过 CLIProxyAPI 测通的文本模型当作虚构受访者。它比较模型能否遵照给定观念作答，以及问卷能否把这些回答归到预期的参考画像。它不用于推断模型、用户或人群的真实政治立场。

每个角色先在各候选模型上完成 15 道独立探针。事先为每个角色指定 3—5 道关键探针及预期答案；按这些题的平均绝对误差选择候选，并列按候选顺序处理。入选模型再用新的无历史请求回答正式问卷。模型只能看到定性的角色说明和当批题目，不能访问仓库、工具、标准答案、评分锚点或参考坐标。这里的隔离是**请求和权限隔离**，不是对代理服务端实现的审计。

正式测试用仓库原有的题库、补充题和澄清题触发规则以及归纳函数。三个模型各进行一组无角色提示对照。候选并非 API 的全部模型，角色观念也只是便于检查的操作化定义，不能视为社会共识。每个角色只有一次正式模拟，不能替代真人试测。

## 查看与复算

- [v2.1 报告](results/报告.md)和 [v2.2 报告](results-v22/报告.md)分列当时的内部归纳与当前网页规则的离线回放。原始提示曾直接写出自由意志主义、绿色政治、发展型国家取向三个名称；后续提示已删去这些名称，旧实验不追溯为盲测。两版均有效的 22 个角色中有 15 个使用同一模型，不能把差异单独归因于改题。
- `results/protocol.json` 保存角色、探针、预期值及参考资料；`results/pilot.json` 保存候选比较；`results/results.json` 保存正式答卷与对照；`results/calls.jsonl` 保存实验请求状态与通过校验的回答。
- `node experiments/ideology/report.mjs experiments/ideology/results experiments/ideology/recovery` 用原有计分函数复核已保存的答卷并重建报告，不发网络请求。省略最后一个目录则只生成初测报告。
- `node experiments/ideology/run.mjs <新结果目录>` 会调用 CLIProxyAPI，可能消耗配额。默认从 `~/.pi/agent/cliproxyapi.json` 读取配置，可用 `CLIPROXYAPI_CONFIG` 指定其他配置文件。配置和凭据不写入实验产物。实验仅向模型发送仓库公开题目与合成提示，不发送真实受访者答案。
- `node experiments/ideology/sensitivity.mjs` 用原答卷回放新的候选展示，并重建[关键维度敏感性检查](results/敏感性检查.md)。这是离线分析，不会替换线上计分或归纳规则。

今后的初测超时或返回无效回答时，可以用 `node experiments/ideology/run.mjs <新补测目录> <对应初测目录>` 对失败角色和对照补测。题库、提示或归纳版本改变后不追加到原实验。归档归纳模块来自冻结的 v2.1 下载包，仅用于离线复核原实验，不随网站发布。补测沿用入选模型和角色提示，把基础题分成四批，每批 24 道，结果不覆盖初测。

`experiments/` 不在网站构建的发布白名单内。
