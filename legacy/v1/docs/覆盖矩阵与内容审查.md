## 已完成的设计检查

- 数量：120道核心候选题，80道正式、40道备用；12道情境题和4道反馈，共96道作答题。
- 平衡：每维度正式题4正向、4反向；每个20题区组覆盖全部维度，正反方向交错。正反平衡只能减少单向赞同影响，不保证消除措辞效应。
- 表述：不使用具体政党、领导人或当前国家政策作为评分标准。D1_01由依赖“现在税率”的表达改为累进税原则；D4_02将“较长时期”改为一年。
- 计分：未知、题意不清与跳过分别保留；中立与双向抵消分别解释；没有人格、能力或政治正确性评分。
- 情境：六组各两题明确描述条件变化，保留选择原文，不将改选视为不一致。
- 解释：标签为局部参考，参与式民主社会主义提示同时要求自由与制衡方向，避免只凭规划和再分配推导“民主”；国家自主与共同文化提示不推导对外强硬。

## 尚未解决的测量问题

| 风险 | 影响 | 后续处理 |
|---|---|---|
| D2包含所有权、市场价格、劳动治理 | 不一定是同一因素 | 先检验结构；必要时拆为所有权与市场干预 |
| D3的公共卫生限制与其他自由题 | 公共卫生判断不一定代表普遍秩序倾向 | 认知访谈和跨负荷审查；可替换或仅作情境题 |
| D4中央地方、任期上限受制度类型影响 | 联邦制或议会制经验可能改变理解 | 检查制度语境偏差；不假定各国同义 |
| D5的专家授权与代表授权不同 | 低分不等于反对民主 | 结果端点保留两种机制，结构不支持则拆分 |
| D6包含生命伦理、传统延续与个人自主 | 无法用一轴完整表达所有文化立场 | 报告分布；不从保留节庆推导反对权利 |
| D7共同身份与公民普遍主义 | 支持统一规则不必然排斥少数群体 | 追问动机，检验形式平等和文化同化是否分开 |
| D8全球合作与D10生态题交叉 | 减排可能拉高两个维度关系 | 检验跨负荷；采用非环境全球合作备用题比较 |
| D9威胁判断和国家处境 | 小国与大国经验可能不同 | 访谈和群体检查；不解释为人格上的好战或和平 |
| D10生活成本与收入约束 | 反对某政策可能是负担能力而非轻视环境 | 访谈区分条件与价值，必要时加入明确补偿条件 |
| 多项题目提及执行成本不对称 | 权利端可能显得更有道德，安全端更依赖风险 | 独立盲审及访谈检查社会赞许与措辞强度 |
| 只含中文原创题 | 无跨文化等值性证据 | 多地区试测；翻译后另行验证 |
| 固定阈值与思想传统词典 | 可能造成边界效应和标签锚定 | 作为解释假设公开，不宣传分类准确率 |
